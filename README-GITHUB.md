# Simple Python IDE

This folder contains a lightweight Python IDE built with PySide6.

## Run locally

1. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
2. Start the app:
   ```bash
   python launch.py
   ```

## Files

- app.py: the main application
- launch.py: simple startup entry point
- requirements.txt: required package
